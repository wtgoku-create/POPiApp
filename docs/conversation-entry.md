# 会话入口与首次发送

更新日期：2026-10-16

## 功能目标

账号主页根据服务端绑定状态提供“开始一条新内容”或“继续对话”。新建项目对话先进入初始化页，用户首次发送有效内容时才确定或创建会话，避免浏览入口就产生空会话。

## 账号主页

| 状态 | 按钮 | 点击行为 |
| --- | --- | --- |
| 正在查询绑定 | loading 图标，按钮禁用 | 等待查询完成 |
| 无绑定会话 | 开始一条新内容 | 进入账号专属会话初始化页 |
| 已绑定会话 | 继续对话 | 直接进入对应会话，加载历史消息 |
| 查询失败 | 保留原操作入口，Toast 提示 | 再次点击时重新查询，成功后跳转 |
| 账号不可编辑 | 按钮禁用 | 不创建会话 |

打开或刷新账号主页时查询绑定；从会话页返回后重新加载绑定，更新按钮文案。查询失败不视为没有绑定。

## 初始化页与首次发送

1. 账号入口使用 `/session?accountId=<账号 ID>`，不携带会话 ID，不自动填入示例文案，不创建会话，也不加载其他会话历史。
2. 用户可以输入文字、添加图片、选择素材和角色、配置模型参数。模型参数先保存在本页草稿中；打开和确认参数面板不会创建会话。
3. 首次发送前校验内容及附件上传状态。无文字且无附件、素材或角色时不发送。
4. 账号草稿发送时再次查询该账号的绑定会话：存在则复用；只有服务端明确返回 `404 ACCOUNT_SESSION_NOT_FOUND` 才创建并绑定会话。
5. 查询与创建之间若其他客户端已完成绑定，创建接口返回 `409 ACCOUNT_SESSION_EXISTS` 时重新读取并复用绑定会话。
6. 确定会话后立即把路由更新为 `/session?sessionId=<会话 ID>`，再保存草稿模型参数并发送用户输入和附件。切换路由保持同一发送过程，不清空待发送内容。
7. 消息成功发送后清空输入与附件，展示该会话消息；后续发送复用当前会话。

## 通用新建入口

- 侧边栏“新建项目对话”和会话页右上角“新建对话”都进入 `/session` 初始化页，不调用创建接口，不增加侧栏历史记录。
- 在初始化页再次点击新建也会清空当前草稿。新建操作清除账号上下文、已选附件、角色、素材和草稿模型参数。
- 普通初始化页首次发送时创建一个通用会话，然后保存参数并发送消息。
- 未登录时点击新建或发送进入登录页，不创建会话。

## 失败、重试与隔离

- 绑定查询失败：Toast 提示，保留文字和附件；再次发送重新查询，不提前创建。
- 创建超时或结果不确定：按登录用户、账号和请求内容持久保存创建请求 ID；重试先查绑定，没有绑定时复用原创建请求，避免重复创建。
- 会话已确定但参数保存或消息发送失败：保留路由和草稿，再次发送复用同一会话。
- 请求进行中禁用重复发送。离开页面、切换会话、开始新草稿或切换登录用户时取消旧请求；迟到的结果不得覆盖新页面或发送旧输入。
- 失败提示通过统一 Toast 展示，不增加错误面板或把发送按钮改为重试按钮。
- 未发送草稿仅在当前页面内保存，离开页面或重启应用不会恢复；创建结果不确定时使用的请求 ID 持久保存以支持安全重试。

## 使用接口

| 目的 | 接口 |
| --- | --- |
| 查询账号绑定会话 | `GET /api_agent/v2/sessions/by-account/{accountId}` |
| 创建账号绑定会话 | `POST /api_agent/v2/sessions`，带 `accountId`、`title`、`clientRequestId` |
| 创建通用会话 | `POST /api_agent/v2/sessions`，不传 `accountId` |

沿用现有会话快照、SSE、消息发送与模型偏好接口。没有新增后端接口。

## 验收重点

- 账号已绑定：主页显示继续对话，进入原会话，不创建新会话。
- 账号未绑定：进入初始化页和编辑参数均不创建，首次发送才查询并创建。
- 进入初始化页后账号被其他客户端绑定：首次发送复用新绑定，用户输入仍正确发送。
- 查询失败不创建；创建超时重试复用请求 ID；并发创建冲突恢复到绑定会话。
- 首条消息发送失败保留草稿和会话 ID，重试不重复创建。
- 侧栏和右上角新建均延迟创建；新建时清空旧草稿和账号上下文。
- 切换用户或新建草稿取消旧请求，重复点击只执行一次。
- 中英文、深浅主题、小屏侧栏布局和长按菜单保持正常。
