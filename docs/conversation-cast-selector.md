# 输入框出场角色选择

更新日期：2026-10-16

## 入口与展示

会话输入框新增出场角色按钮，未选择时显示“未匹配”，一个角色时显示头像和名称，多个角色时显示最多三个头像及角色数量。点击打开角色库，按选择顺序最多选择五个角色，允许全部取消。

已有会话优先展示服务端快照的 `sessionCast`，空数组表示明确清空。旧快照缺少该字段时，按事件序号回放角色上下文、发布角色及已完成的角色工具调用，与 Web 端保持一致。

## 接口与生命周期

- 已有会话确认后调用 `PUT /api_agent/v2/sessions/{id}/cast`，请求体为 `clientRequestId` 和数值数组 `roleIds`，不传 `reply: false`，沿用 Web 默认触发 Agent 回复的行为。
- 清空角色提交 `roleIds: []`；成功后刷新快照。请求超时或结果不确定时保留请求 ID，同一选择重试复用该 ID。
- 新建会话初始化页只保存角色草稿，不创建会话；首次发送时沿用现有发送流程，先保存角色（`reply: false`），再发送消息，避免重复触发回复。
- SSE 的 `context.recorded` 中，`cast.updated` 且来源为 `session_cast` 或 `conversation_cast` 时更新当前会话角色；其他创建流程的角色上下文不覆盖服务端会话角色。

## 交互状态

- 加载、请求提交、Agent 运行、连接断开、会话未绑定完成或归档时，已有会话的角色选择不可提交。
- creatorV1 会话选择可读角色；旧会话还要求角色已有档案版本。
- 请求失败通过统一 Toast 提示，保留面板选择、输入文字及附件，允许再次确认。
- 切换会话或登录用户后取消旧请求，迟到结果不得修改新会话草稿。
- 角色库的创建角色入口关闭面板，并将创建角色提示填入输入框，由用户发送。

## 验证

覆盖接口参数、清空、超时复用请求 ID、角色历史回放和 SSE 更新；覆盖初始化页不提前创建、失败保留草稿、状态禁用、重复提交、切换取消，以及窄屏和大字体布局。
