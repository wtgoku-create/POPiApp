# POPi 本机管理台

独立于 Flutter App 的简易 Web 后台，直接读取本机 Harness Agent 服务，不依赖新安装的包。

## 启动

先按 [本地开发指南](../docs/local-development.md) 启动本机 Agent，再在项目根目录运行：

```bash
node admin/server.mjs
```

要求 Node.js 22 或更新版本。打开 <http://127.0.0.1:7360>。App 继续使用原来的 `7357` 端口。
默认从 `config/env/harness.json` 读取 `AGENT_API_BASE_URL` 与 `AGENT_API_ORIGIN`。
代理发送配置中的 Origin，因此不必调整 Agent 的浏览器来源白名单。

自定义端口或配置文件：

```bash
node admin/server.mjs --port 7361 --env /absolute/path/to/harness.local.json
```

配置只允许本机回环 HTTP 地址。后台不连接公网生产服务，不读取 App Token、模型密钥或 Agent 私有状态文件。

## 功能

- **运行总览**：健康状态、Harness 版本、文字模型、多模态与联网能力，以及会话和素材数量。
- **会话与任务**：服务端每页 20 个会话，支持归档筛选、本页名称/ID 搜索、本页任务状态筛选；详情显示最近 50 条文字运行、50 条媒体任务和 30 条消息。
- **管理操作**：重命名、归档/取消归档、停止文字运行；确认后同步到 App 使用的同一服务。停止文字运行不会取消已经提交的媒体任务。
- **素材库**：名称/ID 搜索、类型筛选，每页 12 项，图片预览、视频/音频播放、下载与所属会话查看。
- **刷新**：每 5 秒自动读取；页面隐藏或确认操作期间暂停轮询，可关闭自动刷新或手动刷新。读取失败时保留上次结果并标记未同步。

文字和媒体任务的进行中/失败数量仅统计**当前页会话的历史任务**，不代表全局任务数量。
媒体生成完成但尚未保存时显示“保存中”，保存失败单独显示。结果未知不计作成功或失败。
服务未提供运行时间、成本与用户实体，因此不展示耗时、费用、活跃用户等估算指标。
素材接口当前不支持服务端分页；后台仅对返回列表分段渲染，适合本机联调数据量。

后台只监听本机地址，代理有明确的路径、方法和字段白名单，并校验同源写请求。
无需管理员账号；不适用于公开部署或线上多用户管理。所有数据保存在原 Agent 服务，由它负责持久化。

## 验证

```bash
node --test admin/*.test.mjs
node --check admin/public/app.js
```

接口测试使用独立的假服务和临时目录，不修改真实会话或触发模型生成。
